Challenges

Challenges and Fixes

  • Large SAS file was slow to load, filtered to 2018, kept needed columns, saved a smaller CSV.
  • Missing values existed so I dropped columns with NAs; used drop_na() for modeling data.
  • Provider codes were just numbers so I mapped them to hospital names with case_when().
  • Random forest took a long time to train, so I trained on a 10% sample with tuneLength = 3.
  • Warnings/messages cluttered the output so I had to include message=FALSE, warning=FALSE on each chunk.
